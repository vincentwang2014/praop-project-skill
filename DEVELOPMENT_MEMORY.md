# Development Memory

> What must not be forgotten? This is not a changelog — git already has
> that. This is for things a new agent, or a human returning after a
> gap, would otherwise have to rediscover the hard way. See `SKILL.md`
> for when to update this file.

## Decisions

Decision — why — date. Only decisions that would be easy to accidentally
reverse or relitigate without this record.

## Assumptions

What is currently assumed true but not fully verified? Mark each as
still valid or stale. An assumption that turned out wrong belongs in
`LESSONS_LEARNED.md`, not silently deleted from here.

## Environment Facts

Standing facts about the environment that don't need re-explaining every
session — credentials already present, access already granted, naming
conventions already fixed, and similar.

## Recurring Conventions

Patterns this project follows that aren't obvious from the code alone.

## Things Future Agents Must Know

Anything that doesn't fit the categories above but would cause real
damage if missed.
