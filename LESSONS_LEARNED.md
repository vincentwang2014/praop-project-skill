# Lessons Learned

> What have we already learned the hard way? Every entry must pass the
> EDTCU Test before it's saved: can this be explained in plain language
> to the human who owns the outcome? If not, rewrite it before it goes
> in this file. See `SKILL.md` for the full discipline around when and
> how to add entries — most sessions add nothing here, and that's fine.

## Entry format

Copy this block per lesson:

```
### <short title>

**Date:**
**Observed:** what actually happened, factually, no interpretation.
**Interpretation:** what you think it means. Keep this separate from
  Observed — see Open PRAOP §3, "Assert Incidents, Hedge Abstractions."
**Evidence level:** E0–E3 (see Open PRAOP §8). Most agent-captured
  entries are E0 — that's fine, just say so honestly rather than
  inventing a different label for the same thing.
**Confidence / Status:** starts at `Observed / Active` (see Open PRAOP
  §9). Don't self-promote — that needs a second independent incident
  and a human call, not the agent's own judgment.
**Working recommendation:** what to actually do differently, stated as
  a working recommendation, not a universal rule.
```
